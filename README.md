# Dyson Landing Page

Лендинг страница для бренда Dyson.

## Структура проекта

```
17(dyson)/
├── index.html          # Главная страница
├── css/                # Стили
│   ├── fonts.css       # Подключение шрифтов
│   ├── reset.css       # Сброс стилей
│   ├── style.css       # Основные стили
│   └── swiper-bundle.min.css  # Стили для слайдера
├── js/                 # JavaScript файлы
├── fonts/              # Шрифты (NAMU-Pro, OpenSans)
└── img/                # Изображения
```

## Технологии

- HTML5
- CSS3
- JavaScript
- Swiper.js (слайдер)

## Запуск

Откройте файл `index.html` в браузере.
